# change-passport-test

A test repository used for experimenting with repository automation and workflows.

## Overview

This repository currently contains no application code. It serves as a sandbox for
trying out changes, automation and tooling in an isolated place.

## Getting Started

Clone the repository and start working in it locally:

```bash
git clone https://github.com/mehrshadshams/change-passport-test.git
cd change-passport-test
```
